## 2025-05-18 - Calendar Grid & Task Grouping Memoization
**Learning:** In calendar components rendered within React, calculating grid arrays (`days`) and grouping events (`eventsByDate`) directly in the component render function causes unnecessary array allocations and O(N) array iteration work on every re-render (such as toggling modal state or hovering UI elements). Additionally, mounting inactive modal components (e.g., `TaskModal`) keeps unnecessary React fiber nodes and internal state mounted.
**Action:** Wrap grid array generation and data grouping/reduction operations in `useMemo` hooks, conditionally mount modal components (`isModalOpen && <TaskModal ... />`), and use `isMounted` cleanup flags in `useEffect` state updates to prevent cascading re-renders and ESLint warnings.
